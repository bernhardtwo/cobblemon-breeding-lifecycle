# 0008 · Optional adapter on `COLLECT_EGG`

Status: accepted (2026-10-21)

## Context
Cobblemon 1.7.3 declares `COLLECT_EGG` and never fires it; Daycare+ fires it when an egg is produced, with the real
tethered parents, and Cobbreeding fires it on collection with blank `new Pokemon()` placeholders
([breeding-hooks](../research/breeding-hooks.md)). S11 wants the loss applied there without mixins.

## Decision
- `EggEventAdapter` always subscribes and reads `eggEventAdapter.enabled` on every event, so a reload switches it.
- A parent is real when its store coordinates point back at it and the store is a party or a PC. If either parent
  is not, the event is ignored with a warning in the server log; nothing is counted or audited.
- Otherwise it calls `evaluate(male, female, "egg-event")` and removes each lost parent from its store.
- A lost parent in a pasture (`tetheringId != null`) is untethered first by clearing `tetheringId`, then removed from
  its PC. That is safe in Cobblemon 1.7.3: the pasture's own `releasePokemon` does the same
  ([PokemonPastureBlockEntity.kt#L313-L318](https://gitlab.com/cable-mc/cobblemon/-/blob/1.7.3/common/src/main/kotlin/com/cobblemon/mod/common/block/entity/PokemonPastureBlockEntity.kt#L313)),
  its periodic `checkPokemon` drops tetherings whose Pokémon is gone from the PC
  ([#L291-L304](https://gitlab.com/cable-mc/cobblemon/-/blob/1.7.3/common/src/main/kotlin/com/cobblemon/mod/common/block/entity/PokemonPastureBlockEntity.kt#L291)),
  and the pastured entity discards itself once the Pokémon's `tetheringId` no longer matches
  ([PokemonServerDelegate.kt#L298-L301](https://gitlab.com/cable-mc/cobblemon/-/blob/1.7.3/common/src/main/kotlin/com/cobblemon/mod/common/entity/pokemon/PokemonServerDelegate.kt#L298)).
  So the `skipped` audit result is never needed by the adapter.
- Cancelling the event is not used: neither breeding mod checks it.

## Consequences
- Works with Daycare+ while the pasture owner is online; Cobbreeding's events and Daycare+'s offline eggs are
  ignored (out of scope without mixins).
- The egg is generated by the other mod either way; only the parents are affected.
