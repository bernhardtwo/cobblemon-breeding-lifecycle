# 0004 · CLI screenshots with freeze

Status: accepted (2026-10-21)

## Context
The README needs PNG captures of the CLI in both languages, reproducible without a person at the terminal.

## Decision
`scripts/cli-screenshots.sh` pipes each command's real output, prefixed with the command line, into
[`freeze`](https://github.com/charmbracelet/freeze) as plain text. `freeze --execute` was dropped: it waits on a
terminal and hangs when run headless. `simulate` uses `--seed 42` so the image is stable between runs.

## Consequences
Screenshots are regenerated by one command after any output change; colours come from freeze's `dracula` theme.
